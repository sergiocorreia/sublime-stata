# Optional research examples

This directory contains project-specific reference material supplied with the repository:

- `STATA_STYLE_GUIDE.md` is the source of truth used to shape the package's snippets and editing
  defaults.
- `common.do`, `dodo.ado`, `play.do`, the graph scheme, and the sound file are examples from a research
  workflow. They contain project paths and assumptions that will not apply to every installation.

Sublime Stata does **not** install, source, copy, or execute these files automatically. Use or adapt
them only when intentionally setting up a compatible research project.
